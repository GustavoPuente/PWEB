# Study Manager — Projeto Final PWEB

Aplicação web Kanban com o tema **Planejamento de Estudos** (Conteúdo para estudar / Em Progresso / Concluído).

- HTML, CSS e JavaScript puro
- Criar, editar e excluir cartões
- Arrastar e soltar entre colunas
- Avisos de prazo (atrasado / próximo / concluído)
- Pesquisa e filtro por prioridade
- Dados salvos no Firebase Firestore (com cópia no `localStorage`)
- Próximo feriado via [BrasilAPI](https://brasilapi.com.br)
